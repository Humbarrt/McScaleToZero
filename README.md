# MCScaleToZero

**MCScaleToZero** lets you run a **Minecraft server that scales with your playtime** — minimizing cost when idle and distributing expenses fairly. Whether you’re playing daily or taking a multi-month break, this setup ensures you **only pay for what you use**.

> 💡 Why pay \$8/month for an idle Minecraft Realms server when your actual playtime might not justify it?

Our **fixed monthly cost is just \$1.40 (pre-tax)** — and usage-based billing ensures **you’re only charged for the CPU time you consume**. For example, if you're not playing, you only pay a small portion of shared infrastructure costs. If you do play, you pay based on the computing time, not per player — so **10 friends online costs the same as playing alone**.

## 🚀 Features

* ✅ **Auto-scaling Minecraft Server on AWS**
* 📊 **Playtime & CPU usage statistics**
* 🤝 **Splitwise integration** for automatic cost sharing
* 💱 **Free currency conversion** for billing fairness
* 🧾 **Server MOTD and icon customization**
* 💾 **Automated backups**
* ⚖️ **Fairness** only pay for how much you play!
